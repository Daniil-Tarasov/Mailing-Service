# Сервис для отправки рассылок

## Описание

Сервис для отправки рассылок - сервис для отправок рассылок клиентам.
CRUD рассылок, клиентов и сообщений выполнен на фреймворке Django, PostgreSQL используется для сохранения данных.
Также осуществлены функции:
1. Отправка рассылок через командную строку
2. Создание суперпользователя через командную строку
3. Создание группы "Менеджеры" через командную строку

## Установка

Клонируйте репозиторий:

```
git clone git@github.com:Daniil-Tarasov/Web-shop.git
```

Установите зависимости:
```
poetry install
```

## Использование

1. Откройте скопированный проект.
2. Переименуйте файл ".env.sample" в ".env" и укажите свои данные
3. Запустите сервер с помощью команды `python manage.py runserver` или `python3 manage.py runserver`
4. Для создания суперпользователя используйте команду `python manage.py csu` или `python3 manage.py csu`
5. Для отправки сообщения можно использовать команду `python manage.py send_mailing <id_рассылки>` или `python3 manage.py send_mailing <id_рассылки>`
6. Для создания группы "Менеджеры" используйте команду `python manage.py create_managers_group` или `python3 manage.py create_managers_group`
